## 权威性说明

- **产品形态**以 `docs/product/PRD-产品需求文档.md` 与
  `docs/design/详细设计文档-阶段五-通用管理台重塑.md` 为准（阶段五已将产品从「只读审计
  看板」重塑为「通用 Skill/MCP 管理台」，早期文档中「只读看板」「刻意不做写入型 GUI」等
  表述已失效）。
- **实现细节**以阶段五 + 代码为准；各阶段文档中的 `阶段 X` 章节按对应阶段阅读。
- **决策结论**以 `docs/decisions/决策记录-待决问题定案.md` 为准。
